# Career Progression & Retention Analytics

A Streamlit dashboard for exploring employee career progression, promotion gaps,
career-pattern segments, and historical retention patterns. The dashboard
supports exploratory analysis; it does not predict individual employee attrition.

## Features

- Filter analysis by department, job role, promotion-gap category, and
  intervention priority.
- Upload any CSV for an interactive data profile, quality checks, numeric
  distributions, category breakdowns, and a downloadable CSV.
- Review headline indicators, promotion-gap distributions, department and role
  comparisons, and retention-intervention priorities.
- Navigate between an executive overview and the full analysis, with shared
  department, role, promotion-gap, and intervention filters.
- Compare promotion-gap patterns by department, job role, job level, and tenure.
- Explore observed attrition by workforce group and compare exploratory
  Logistic Regression and Random Forest benchmarks.
- Review filtered, data-backed management observations with sample sizes and
  responsible-use caveats.
- Explore career clusters and their silhouette-score evaluation.
- Search employee records and download the filtered results as CSV.
- Generate analysis outputs from the source dataset with vectorized scoring and
  K-means clustering.

## Quick start

Use Python 3.10 or newer. From the project directory, create and activate a
virtual environment, then install dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Place one employee CSV dataset in `data\`. The dataset must include the columns
used by `src\career_model.py` (including `Attrition`, `Department`, `JobRole`,
career-tenure fields, satisfaction, involvement, and work-life balance).
Generate the analysis outputs and launch the dashboard:

```powershell
python src\career_model.py
streamlit run app.py
```

The dashboard reads its prepared data from `outputs\`. Re-run the analysis
script after replacing or updating the source dataset.

To explore a different CSV, upload it in the dashboard sidebar. Generic CSV
analysis works independently of the career-model column requirements; the
uploaded file is processed in memory and is not written to the project.

## Optional Google sign-in

The dashboard includes optional Google OpenID Connect sign-in. Create a Google
OAuth **Web application** client and add the dashboard's callback URL to its
authorized redirect URIs. For a local run, the callback URL is
`http://localhost:8501/oauth2callback`; add the corresponding URL for your
deployment as well.

Create `.streamlit\secrets.toml` (this file is ignored by Git) with the values
from your OAuth client:

```toml
[auth]
redirect_uri = "http://localhost:8501/oauth2callback"
cookie_secret = "replace-with-a-long-random-secret"
client_id = "your-google-oauth-client-id"
client_secret = "your-google-oauth-client-secret"
server_metadata_url = "https://accounts.google.com/.well-known/openid-configuration"
```

Keep the client secret and cookie secret private. Restart Streamlit after
configuring the secrets. Until these settings are present, the sign-in button
is disabled; sign-in is optional and does not restrict dashboard access.

## Outputs

`src\career_model.py` writes:

- `employee_career_scores.csv` — employee-level career indicators, scores,
  intervention priority, and cluster assignments.
- `career_cluster_summary.csv` — aggregate characteristics of each cluster.
- `clustering_evaluation.csv` — silhouette scores for the evaluated cluster
  counts.

Other existing analysis artifacts in `outputs\` are generated by the exploratory
analysis scripts.

## Methodology and responsible use

Promotion-gap categories and intervention priorities are transparent,
rule-based heuristics. They are not validated risk scores or probabilities of
resignation. Attrition model benchmarks use a stratified train/test split and
cross-validation for retrospective evaluation only; they do not produce
individual employee risk scores and are not validated for future prediction or
employment decisions. Age, gender, marital status, employee identifiers, and
derived career-risk scores are excluded from those benchmark features, although
other inputs may still act as proxies. K-means clusters describe similarity
across selected career and workplace features; `Attrition` is deliberately
excluded from clustering. Silhouette scores assess cluster separation, not
business value or fairness.

`EmployeeRecordID` is a generated row reference, not a verified employee
identifier. Employee-level exports may contain sensitive information. Confirm
data permissions and organizational privacy requirements before sharing
dashboard results or downloaded records.
